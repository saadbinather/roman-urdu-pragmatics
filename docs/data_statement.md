# Data statement (draft)

## Intended use

The corpus is intended for controlled evaluation of model behavior on pragmatic intent classification in English, Roman Urdu, and code-switched messages.

## Composition

The current export contains researcher-authored, context-conditioned examples organized into matched scenario families. It is a pilot instrument, not a representative sample of language use.

## Annotation status

Existing labels should be treated as provisional until independent annotators fluent in the relevant varieties review the items. Future releases must record annotator IDs, adjudication decisions, agreement, and changes to the label ontology.

## Risks and limitations

Roman Urdu has substantial spelling and orthographic variation. Translational matching can remove culturally meaningful pragmatic cues, while researcher-authored examples can encode the authors' assumptions. Small matched sets also make estimates sensitive to individual scenarios.

## Release policy

Only release text with documented provenance and licensing. Keep private or sensitive text out of version control. Every extension should include a source, language variety, annotation status, and rationale for inclusion.
